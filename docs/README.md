# Documentation

Documentation for people who write conventions, people who consume them, and anyone who wants to know why the
repository works the way it does. Each document is one kind, in the sense of [Diátaxis](https://diataxis.fr/): a
how-to guide gets a task done, reference states the facts, and explanation gives the reasons.

| Document | Kind | Read it when you want to |
| --- | --- | --- |
| [Consuming the conventions](consuming.md) | How-to | check a repository against a release: pin it, run the checks, declare outputs, add a waiver |
| [Authoring conventions](authoring.md) | How-to | propose or change a convention, a requirement or a term |
| [The conventions](../engineering-conventions/definitions/conventions/README.md) | Reference | look up a convention or requirement by ID |
| [How this repository is organized](repository.md) | Reference | know where a file goes: the layers, tool configuration, the toolchain |
| [Versioning](versioning.md) | Explanation | know what a release number promises and how to upgrade |
| [Decisions](decisions/README.md) | Explanation | understand why the repository is designed the way it is |
